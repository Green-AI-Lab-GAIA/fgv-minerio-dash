# Conhecimento do Subsolo (dashboard)

Map of Brazil showing where the class A NI 43-101 reports (SEDAR+) bring field data about the ground, with the
reports behind every colour.

- Run: `./run.sh` (opens http://localhost:8770/dash_conhecimento_solo/). The server root is `02_FGVEnergia/`, so the
  "abrir PDF" and page links open the local PDFs at the cited page.
- Refresh data after rebuilding `sedar_ni43101/geo_brasil/geo_brasil.gpkg`: `./run.sh --preparar`
  (uses the geopandas env in `~/miniforge3/envs/paper_seg_class_culturas`; override with `GEO_PY=...`).
- Layers (left panel): points (drill holes, samples, deposits, project centres), ANM processes (SIGMINE polygons),
  municipalities (IBGE). Any combination can be on; "ativar tudo" turns all of them on.
- Points and processes are drawn as a hexagon heatmap (cell size adjustable) or as markers; municipalities as a
  choropleth in a separate warm scale.
- Colour metric: distinct reports, reports with new data only, or diluted (each report spreads a total weight of 1
  over its items, so heavily drilled projects do not dominate).
- Filters: point type, coordinate precision, state check, information type, commodity, SEDAR+ filing year,
  new-data-only, free-text search on issuer/project/title.
- Hover shows the reports of the area; click lists every reference with pages and PDF links.

Files: `index.html`, `css/estilo.css`, `js/app.js`, `data/*.json` (generated by `preparar_dados.py`),
`data/brasil_municipios.topojson` (IBGE municipalities, copied from the estoque-do-solo project).

## Dados públicos SGB/CPRM (scrapers_sgb)

The dashboard also shows the public data collected by `scrapers_sgb` (GeoSGB, P3MGeo, PDAC, RIGeo). They load from
`data/sgb.json` and `data/sgb_geoquimica.json`; if these files are missing the dashboard works as before.

- Refresh: run the scrapers (output in `<repo>/data` by default, see `scrapers_sgb/__main__.py`), then
  `./run.sh --preparar-sgb` (or `SGB_DATA=/caminho/data ./run.sh --preparar-sgb`). Only the Python standard library is needed.
- Point layers (heatmap or markers on a canvas): ocorrências minerais (~36 mil), recursos minerais PDAC 2024,
  amostras geoquímicas (~365 mil), geocronologia, gravimetria, magnetotelúrico.
- Areas (drawn as outlines in both modes): aerolevantamentos, projetos geoquímicos, folhas geológicas 1:50.000,
  distritos auríferos. Clicking an area lists every active area that covers the clicked spot.
- New colour metrics: **Tipos de dado** (how many active layers have data in the cell) and **Registros** (everything
  in the cell added up). The SEDAR+ metrics ignore SGB points; turning on the first SGB point layer switches to
  "Tipos de dado".
- Filters: commodity also filters SGB occurrences and PDAC resources (and gold districts); free-text search covers
  SGB names, places and projects; sample type (geochemistry) and occurrence importance have their own chips.
- Details: geochemical samples, projects and 1:50k sheets link to their report in RIGeo (metadata joined from
  `rigeo/rigeo_all.jsonl`).
